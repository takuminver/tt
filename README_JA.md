# AIゲーム実況（Android試作版）

Android端末上で画面共有を許可し、5秒ごとに画面を取得してML Kitの画像ラベル認識を行い、簡単なルールで日本語コメントを生成してAndroidの音声読み上げで再生する試作アプリです。

## 重要な制限
- これは完成した高性能AI実況者ではありません。
- ML Kitの一般画像ラベル認識なので、ゲーム内の敵・HP・勝敗・操作状況を正確に理解するものではありません。
- 実況は簡易ルールによる文章生成で、会話型AIによる高度な実況ではありません。
- Androidの機種・OS・ゲームによっては画面共有やバックグラウンド動作に制限があります。
- 読み上げ音声が配信アプリに取り込まれるかは、配信アプリと端末の音声共有仕様によります。
- 初回ビルドにはAndroid Studioとインターネット接続が必要です。APKは同梱していません。

## ビルド方法
1. PCのAndroid Studioでこのフォルダを開く
2. Gradle同期を待つ
3. Android端末をUSB接続し、Runでインストールする

このプロジェクトはAndroid Studio用のソース一式です。スマホ単体でソースからAPKをビルドする構成ではありません。
